# D2 diagram (node-and-edge only)

D2 is a diagram language, not a charting one: it has boxes, containers, edges, `sql_table`, `class`, sequence diagrams and grid layouts, and no bar, line or pie. It earns a place here for the three chart types that are really graphs: network, tree and (loosely) dendrogram. For numbers, use another target.

## What it can draw

| chart | support | note |
|---|---|---|
| network, tree | native | `a -> b: weight` edges with automatic layout (dagre or ELK); `direction: down` for trees; built by `cw.py build --target d2` |
| dendrogram, table | approx | the hierarchy without merge heights; a `sql_table` or `grid-columns` container for a small table |
| everything else | none | no data marks at all |

## Syntax essentials

```d2
# Regions to products
direction: right
North -> A: 120
North -> B: 80
"South Region" -> A: 95
```

- Identifiers with spaces or punctuation go in double quotes; an edge label follows a colon.
- `direction: down|right|left|up` sets the flow; `layout: elk` (CLI flag `--layout elk`) packs large graphs better than dagre.
- Containers: `group: { a; b }`; style with `style.fill`, `style.stroke`, `shape: cylinder` and friends.

## Limits

- No numeric axes, so weights are labels only; a weighted network is better served by an image target that scales edge width.
- Nothing renders on GitHub or GitLab; the reader needs the `d2` binary, the playground, Kroki or an editor plugin.
- Trees beyond about 60 nodes and networks beyond about 40 edges become hairballs; filter first (`kb/charts/network.md`).

## Render

- `cw.py build --chart network --target d2 --data edges.csv --x source --series target --y weight --out graph.d2` then `cw.py render --target d2 --in graph.d2 --out graph.svg` when `d2` is installed; otherwise paste the text into https://play.d2lang.com or use Kroki's `d2` endpoint.
